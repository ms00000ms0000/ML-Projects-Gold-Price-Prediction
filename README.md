# 💰 ML Project - Gold Price Prediction  

## 🚀 Overview  
This **Machine Learning project** focuses on **Gold Price Prediction** using the **Random Forest Regressor** model. The model uses key financial indicators — **SPX, GLD, USO, SLV, and EUR/USD** — to forecast the price of gold based on market trends.  

A detailed **Exploratory Data Analysis (EDA)** was performed, including the creation of a **correlation heatmap** to visualize relationships among variables and an analysis of **GLD price distributions** to identify trends and outliers.  

The trained model achieved an impressive **R² score of 0.98**, demonstrating exceptional predictive accuracy. This project highlights the power of **ensemble learning techniques** in **financial market forecasting**, providing valuable insights for smarter investment decisions.  

---

## 🎯 Key Features  
- 💰 **Gold Price Prediction:** Predicts future gold prices using macroeconomic and commodity data.  
- 📊 **Exploratory Data Analysis (EDA):** Analyzes correlations and trends between financial indicators.  
- 🌲 **Algorithm Used:** Random Forest Regressor for high-accuracy ensemble modeling.  
- 📈 **Model Performance:** Achieved an outstanding **R² score of 0.98** on test data.  
- 💹 **Financial Insights:** Supports data-driven investment and market forecasting strategies.

## 🧠 How It Works  
1. **Data Collection:** Import historical financial data containing SPX, GLD, USO, SLV, and EUR/USD values.  
2. **Data Preprocessing:** Handle missing data, normalize values, and prepare features for model training.  
3. **EDA (Exploratory Data Analysis):** Visualize relationships using correlation heatmaps and GLD price distributions.  
4. **Model Training:** Train the Random Forest Regressor on historical datasets.  
5. **Model Evaluation:** Assess model performance using **R² Score** and visual comparisons between actual vs. predicted prices.  
6. **Prediction:** Forecast future gold prices based on financial indicators.
